## 基本邏輯
如果在同一層(同一個 Column)

對於同個群組下面的才適用...
上面的階層肯定比下面的小，因為如果在同一層，如果你的階層又比下面的大，那麼下面的 Block 理應是你的下一層

ex:
可能有這樣的 markdown 結構
```markdown
# Heading1
### Heading3
## Heading2

```
那麼 Heading 3 與 Heading 2 會在同一層，且上面的 Block Heading3 肯定比 下面的 Block Heading2 階層還小

```text
# Heading 1 - ### Heading3
            - ## Heading2
```


如果是這樣的 markdown 結構
```markdown
# Heading1
## Heading2
### Heading3

```
呈現方式要是這樣
```text
# Heading 1 - ## Heading2 - ### Heading3
            
```

而不是這樣
```text
# Heading 1 - ## Heading2
            - ### Heading3
```

但如果是不同群組，則在同一層 還是會有上面的區塊 level 比下面大的情況，
**或許是一種可以用來判定是否是群組邊界的方法？**
Heading B 屬於 Heading A 群組，
paragraph c 屬於 Heading C 群組，
而依照架構 Heading B 與 paragraph c 在同一層(Column)。
```markdown
## Heading A
### Heading B
paragraph a
paragraph b
## Heading C
paragraph c

```
呈現方式會是

```text
## Heading A - ### Heading B   - paragraph a
                               - paragraph b
## Heading C - paragraph c
```
