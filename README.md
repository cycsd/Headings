# Headings

想要快速的瀏覽目前文件的大綱嗎？
常常不知道你現在編輯的位置是在大綱的哪個階層嗎？
或者想要重複利用一樣的標題、一樣的標題階層來構思你的筆記？
這款 obsidian 插件提供多樣的標題操作，讓你輕鬆調整你的筆記內容。


## Commands

### 跳轉至...
瀏覽當前筆記的所有標題，將遊標跳至所選擇的標題位置

### 複製...
瀏覽當前筆記的所有標題，選擇想要的標題後可直接將該標題複製至當前位置


### 對齊標題至...
移動標題整體至所選擇的標題至下一個大標題之間，
並修改移動的標題階層與選擇的標題的階層一致。

> [!important]
> 會修改標題階層，以對齊標題階層

範例：
對齊 H5 至 H3，
則會找到下一個比 H3 大的標題(H2)，
將 H5 底下的內容移至 H2 之前，
並且更改 H5 的階層以對齊 H3。

對齊前
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```
對齊後
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

>[!caution]
> obsidian 支援的階層只到 Level 6(######)，
> 如果判斷需要更改階層但超過 Level 6 的標題，皆會以 Level 6 顯示 

範例：

對齊 H3 ✌️ 至 H4。

對齊前
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

對齊後
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```
### 插入至 ...
移動標題整體至所選擇的標題至下一個大標題之間，
會修改選擇的標題階層以符合整體階層，
保持插入的標題正確的歸屬於所選擇的標題之下。

> [!Important]
> 不能插入到自己的子標題底下，也不能插入到當前標題底下，因為自己本身就屬於當前標題了。

> [!Important]
> 無論原標題是否需要更改階層才能符合整體階層，
> 只要插入的標題與被插入的標題之間有階層差距，
> 都會修改原標題的階層，用以保持標準的階層結構設計。

範例：

想將 H4 插入至 H2 ☝️ 底下，

插入前
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

如果標題級距不跟著改，
H4 會變成屬於 H3 的子內容，而不是 H2 的子內容，

```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```
這並不符合操作意圖，所以會修改 H4 的階層至 level 3，
以符合操作意圖，

```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

>[!caution]
> obsidian 支援的階層只到 Level 6(######)，
> 如果判斷需要更改階層但超過 Level 6 的標題，皆會以 Level 6 顯示 

範例：

插入 H3 ✌️ 至 H4 底下，

插入前
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

插入後
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2

```

### 移動標題
移動選擇的標題及其所涵蓋的內容至另一個標題到下一個標題的段落之間。

> [!Important]
> 此指令只是單純的移動標題內容位置，
> 不會更改原有的標題階層。

範例:

如果移動 H1 至 H2 ，那麼會從 H2 找到下一個標題 H3，
將 H1 及底下的 H2 內容，移動至 H3 之前，
並不會改變 H1 底下內容的階層

移動前
```markdown
## H2
### H3
# H1
## H2
```

移動後
```markdown
## H2
# H1
## H2
### H3
```

適用於標題位置調整，
範例：
```markdown
## H2
### H3 
#### H4 ☝️
#### H4 ✌️
```
移動 H4 ✌️ 至 H3 ，則會變為
```markdown
## H2
### H3 
#### H4 ✌️
#### H4 ☝️
```

### 移動區塊至 ...
將當前遊標位置的區塊移至所選擇的標題至下一個標題之間。

### 移動選取範圍至 ...
將當前選取的範圍移至所選擇的標題底下

### 選取內容
選取該標題底下的所有內容
