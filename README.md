# Headings

想要快速的瀏覽目前文件的大綱嗎？
常常不知道你現在編輯的位置是在大綱的哪個階層嗎？
或者想要重複利用一樣的標題、一樣的標題階層來構思你的筆記？
這款 obsidian 插件可以幫助你處理這些問題


## Commands

### Go to Heading
將遊標跳至所選擇的標題位置

### Copy Heading
瀏覽當前筆記的所有標題 ，選擇想要的標題後可直接將該標題複製至當前位置

### Copy Heading Format?
根據所選擇的標題，更動另一個選擇的標題的階層？


### Move Heading
~~將當前遊標所在的標題內容移至所選的標題區塊下~~
移動選擇的標題至另一個標題段落後方,或標題正下方(多一個 modal 選擇?)
與 [Insert Into ...](#insert-into-) 不同的地方在於此指令只是單純的移動標題內容，
不會更改原有的標題階層。

### Insert Into ...
移動標題至所選擇的標題至下一個大階層之間，會修改選擇的標題階層以符合整體階層，
插入到自己的子標題底下？ 不能插入到自己的子標題底下，也不能插入到當前標題底下，因為自己本身就在當前標題了
從小標題移動到大標題底下呢？ 標題級距也要跟著改，才符合需求
例如下方
```markdown
## H2
### H3
## H2
#### H4
```
想將 H4 移動到第一個 H2 底下，如果標題級距不跟著改，
會變成跑到 H3 底下，這並不符合需求
```markdown
## H2
### H3
#### H4
## H2
```


該如何縮減？
如果是這樣原本 H2 的標題移到另一個 H2 底下，

from
```markdown
## H2
#### H4
### H3
```
to
```markdown
### H2
#### H4
#### H3
```
只調 H3 會打亂原本階層，

但如果是這樣
```markdown
## H2
#### H4
#### H4
```
我需要只調 H2 就好，我不應該動到 H4 的標題？
我覺得應該也是要調，才符合原本的配置，只是如果已經超出 H6 但有沒有大過所屬階層才可以保持原樣？
```markdown
### H2
##### H4
##### H4
```

例如
```markdown
## H2
##### H5
##### H5
### H3
```
H2 移動到 H3 之下，要退 2 階，H5 退 2 階會超出 H6 所以不動？ 還是應該也要變成 H6?
```markdown
#### H2
##### H5
##### H5
##### H3
```
看來需要退至 H6 才合理

>[!note]
> obsidian 支援的階層只到 Level 6(######)，
> 如果判斷需要更改階層但超過 Level 6 的標題，皆會以 Level 6 顯示 

### Move Current Block To ...
將當前遊標位置的區塊移至所選擇的標題至下一個標題之間。

### Move Select To ...
將當前選取的範圍移至所選擇的標題底下

### Select Content
選取該標題底下的所有內容
