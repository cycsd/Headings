# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

Obsidian Markdown 노트의 개요와 섹션을 빠르게 정리합니다. 이 플러그인은 제목 탐색, 복사, 선택, 이동, 삽입 및 수준 정렬을 지원합니다. 긴 노트를 재구성하거나 섹션 순서를 바꾸고 제목 계층을 유지할 때 유용합니다.

## 명령

### 제목으로 이동
현재 노트의 모든 제목을 찾아 선택한 제목으로 커서를 이동합니다.

### 제목 복사
현재 노트의 제목을 선택하여 복사하거나, 현재 커서 위치에 제목 표식을 삽입합니다.

### 제목 수준 정렬
제목과 모든 내용을 선택한 제목 뒤, 다음 상위 수준 제목 앞에 이동합니다. 이동한 제목은 선택한 제목과 같은 수준으로 조정되며, 하위 제목도 같은 차이만큼 조정됩니다.

> [!important]
> 이 작업은 제목 수준을 변경하여 정렬합니다.

예: H5를 H3에 맞춰 정렬합니다. 플러그인은 H3보다 상위인 다음 제목(H2)을 찾고, H5와 내용을 해당 H2 앞에 이동한 뒤 H5를 H3과 같은 수준으로 변경합니다.

변경 전:
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

변경 후:
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> [!caution]
> Obsidian은 제목 수준 1부터 6까지만 지원합니다. 조정 결과가 6을 초과하면 제목은 수준 6으로 표시됩니다.

예: H3 ✌️를 H4에 맞춰 정렬합니다.
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

변경 후:
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 다른 제목 아래에 제목 삽입
제목과 모든 내용을 선택한 제목 아래, 다음 상위 수준 제목 앞에 이동합니다. 올바른 부모-자식 관계를 유지하도록 제목 수준을 조정합니다.

> [!important]
> 자신의 하위 제목 아래나 현재 부모 제목 아래에는 삽입할 수 없습니다. 해당 제목은 이미 그 부모에 속해 있기 때문입니다.

> [!important]
> 이동할 제목과 대상 제목 사이에 수준 차이가 있으면, 유효한 계층을 유지하도록 수준을 조정합니다.

예: H4를 H2 ☝️ 아래에 삽입합니다.

삽입 전:
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

수준을 바꾸지 않으면 H4는 H2 ☝️의 직접 자식이 아닌 H3의 자식이 됩니다.
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

의도한 구조를 유지하기 위해 H4는 수준 3으로 변경됩니다.
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> [!caution]
> Obsidian은 제목 수준 1부터 6까지만 지원합니다. 조정 결과가 6을 초과하면 제목은 수준 6으로 표시됩니다.

예: H3 ✌️를 H4 아래에 삽입합니다.
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

삽입 후:
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 제목 이동
선택한 제목과 모든 내용을 다른 선택한 제목 뒤, 그 제목의 다음 하위 섹션 앞에 이동합니다. 제목 수준은 변경하지 않습니다.

> [!important]
> 이 작업은 위치만 변경하며 기존 제목 계층을 유지합니다.

예: H1을 H2로 이동하면 플러그인은 다음 제목 H3을 찾아 H1과 H2 내용을 H3 앞에 이동합니다.

이동 전:
```markdown
## H2
### H3
# H1
## H2
```

이동 후:
```markdown
## H2
# H1
## H2
### H3
```

같은 수준의 제목을 다시 정렬할 때도 사용할 수 있습니다.
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

H4 ✌️를 H3으로 이동한 후:
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 현재 블록을 제목 아래로 이동
현재 커서가 있는 블록을 선택한 제목 아래로 이동합니다.

### 선택한 텍스트를 제목 아래로 이동
선택한 텍스트를 선택한 제목 아래로 이동합니다.

### 제목 내용 선택
선택한 제목 아래의 모든 내용을 선택합니다.
