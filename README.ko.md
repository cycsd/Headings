# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

Markdown 문서를 여러 각도에서 바라보기 위한 플러그인입니다.
노트 하나가 마인드맵 한 장입니다. 제목과 목록 등 원래 있던 단락을 그대로 전체 구조의 그림으로 다시 그려서, 노트의 요점과 구조를 빠르게 파악할 수 있게 합니다.

고칠 곳이 보이면 그림 위에서 바로 손을 댑니다. 상관없는 가지를 접고, 노드를 더블클릭해 내용을 바꾸고, 섹션 하나를 통째로 다른 장 아래로 끌어다 놓습니다. 변경은 모두 노트에 기록되므로 편집기를 위아래로 스크롤하며 잘라 붙일 필요가 없습니다.
그 밖에 보기를 열지 않고도 편집기 안에서 제목으로 이동하거나 복사·이동하고, 어긋난 제목 수준을 맞추는 명령도 한 세트 있습니다.

지금 열어 둔 노트를 그림 한 장으로 그립니다. 그림 위에서 접고, 편집하고, 끌어다 놓으면 변경이 파일에 기록됩니다.

리본 아이콘을 클릭하거나 명령 **Headings 보기 열기**를 실행하면 열립니다.
보기에는 지금 열려 있는 노트가 표시되며, 노트를 바꾸거나 파일 내용이 바뀌면 따라서 갱신됩니다.

### 레이아웃

레이아웃은 세 가지이며 보기 머리글에서 바꿉니다.

- 마인드맵: 노트 이름이 가운데에 있고 제목이 좌우로 뻗어 나갑니다. 휠로 이동, 핀치 또는 Ctrl+휠로 확대·축소.
- 트리 테이블: 제목을 중첩된 셀로 배치하며, 오른쪽으로 한 열 갈 때마다 한 단계 깊어집니다.
- 개요: 가지 선이 있는 들여쓰기 목록.

데스크톱과 모바일 각각의 기본 레이아웃은 설정에서 바꿉니다.
특정 노트만 레이아웃을 고정하고 싶으면 속성에 `headings-layout`을 추가하고 값을 `mindmap`, `tree-table`, `outline` 중 하나로 둡니다. 마인드맵은 오른쪽으로만 펼칠 수도 있습니다. 레이아웃 메뉴에서 **마인드맵: 오른쪽만**을 체크하거나, 설정에서 기본값으로 켜거나, 노트 속성에 `headings-mindmap-direction: right`를 추가합니다.

### 노드

제목 하나가 노드 하나이고, 제목 아래의 단락(본문, 목록, 인용, Callout, 코드, 표, 수식, HTML, 속성, 각주)은 노드 안에 들어갑니다.
노드 위의 아이콘 줄로 유형별로 단락을 보이거나 숨길 수 있습니다. 기본으로 어떤 유형을 보일지는 설정에서 고릅니다.

어떤 유형의 단락을 독립된 노드로 만들고 싶으면(예: 목록의 각 항목을 자식 노드로), 설정에서 그 유형을 체크하거나 노트 속성에 `headings-nodes`를 추가해 지정합니다. 머리글 메뉴에서 잠시 전환할 수도 있습니다.

노트의 속성(frontmatter)은 루트 노드에 속성 패널로 표시됩니다.
노드 안의 체크박스는 바로 체크할 수 있고 파일에 기록됩니다.

### 탐색

보기 상단에 이동 경로(breadcrumbs)가 있어 현재 선택한 노드까지의 경로를 보여 줍니다. 그중 한 항목을 클릭하면 그 단계의 형제 노드가 나열되고, 고르면 그쪽으로 이동합니다.

접기와 펼치기는 몇 가지 방법이 있습니다. 가지가 갈라지는 지점의 손잡이를 클릭하거나, 노드를 선택한 뒤 `Space`로 자식 노드를 접거나 펼치고(`Shift+Space`는 하위 트리 전체), 머리글 메뉴에서 몇 단계까지 펼칠지 지정합니다. **한 단계 펼치기**와 **한 단계 접기**는 명령으로도 있어서 단축키를 붙일 수 있습니다.

노드를 우클릭하거나 `…`를 클릭하면 노드 메뉴가 나옵니다.

- 다른 노드 접기
- 이 노드를 루트로: 이 하위 트리만 표시. 돌아가려면 이동 경로를 클릭
- 이 하위 트리 펼치기 / 접기
- Markdown 파일에서 위치 찾기: 편집기 커서를 이 노드에 해당하는 줄로 옮김

화살표 키로 보이는 노드 사이를 옮겨 다니며 선택할 수 있습니다.

머리글의 검색 버튼, 명령 **노드 검색**, 또는 보기에 초점이 있을 때 `Ctrl/Cmd+F`를 누르면 이동 경로 위에 검색 줄이 열립니다. 제목과 노드 내용의 원문을 비교합니다. 여러 단어는 공백으로 나누면 모두 일치해야 하고, 대소문자는 구분하지 않으며, 따옴표로 구절을 묶을 수 있습니다. 범위는 지금 그려진 트리이므로 **이 노드를 루트로**를 쓴 뒤에는 그 하위 트리만 검색합니다. 그때 검색 줄에 “… 안” 표시가 나타나고, 클릭하면 파일 전체로 돌아갑니다.

검색 줄의 깔때기 버튼으로 두 모드를 전환하며, 마지막 선택을 기억합니다.

- 검색(기본): 트리 전체를 그대로 그리고 일치한 노드를 검색 강조색(편집기의 Ctrl+F와 같은 색)으로 표시하며, 현재 일치는 더 진한 색입니다. `Enter` / `Shift+Enter`로 일치 사이를 이동하며 가운데로 가져오고, 접혀 있으면 가는 길에 펼칩니다. 다른 조작은 모두 평소대로입니다.
- 필터: 일치한 노드와 그 조상만 남기고, 지나가는 길일 뿐인 조상은 흐려지며, 접기 상태는 잠시 무시됩니다. 이것은 “보기” 위한 렌즈이지 편집 작업면이 아닙니다. 추가, 삭제, 드래그, `Space`, 접기 관련 메뉴는 필터 중에 꺼집니다. 선택, 화살표 키, 내용 편집, 체크박스, 위치 찾기, 이 노드를 루트로는 그대로 됩니다.

`Esc`로 검색 줄을 닫으면 트리는 원래 모습으로 돌아갑니다.

### 편집

노드를 더블클릭하거나 `F2`를 누르거나 노드 메뉴에서 **편집**을 고르면, 노드가 Obsidian 편집기로 바뀌고 그 안에 이 노드의 Markdown이 들어 있습니다.
같은 편집기이기 때문에 목록, 링크, 태그, 서식은 노트에서와 똑같이 동작합니다.

`Ctrl/Cmd+Enter`를 누르거나 노드 바깥을 클릭하면 파일에 기록됩니다.
그 밖의 키는 전혀 가로채지 않습니다. `Enter`는 여전히 목록을 이어 쓰고, `Esc`는 여전히 선택을 해제합니다.

노드를 선택한 상태(편집 중이 아닐 때):

- `Enter` 뒤에 형제 노드 하나 추가
- `Tab` 자식 노드 하나 추가
- `Delete` 노드와 그 아래 모든 것을 삭제. 먼저 확인을 묻습니다
- `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` 실행 취소, 다시 실행

추가나 삭제 뒤에는 제목 수준과 목록 들여쓰기가 자동으로 맞춰지므로 직접 고칠 필요가 없습니다.

### 드래그 앤 드롭

노드의 제목 줄을 길게 누르면 끌 수 있습니다.
끄는 동안 자리 표시자가 놓일 위치를 보여 주고, 다른 노드가 자리를 비웁니다.

- 노드 가운데에 놓으면 그 노드의 마지막 자식이 됨
- 노드 위쪽이나 아래쪽 가장자리에 놓으면 그 노드 앞이나 뒤에 삽입됨
- `Esc`로 취소

허용되는 위치만 나타납니다. 제목은 제목 옆에, 목록 항목은 목록 항목 옆에만 놓을 수 있습니다.
놓은 뒤에는 제목 수준과 목록 들여쓰기가 새 부모에 맞춰 조정됩니다.

### 키보드

| 키 | 동작 |
|---|---|
| `↑` `↓` `←` `→` | 선택 이동 |
| `Space` / `Shift+Space` | 자식 / 하위 트리 전체 접기·펼치기 |
| `Enter` / `Tab` | 형제 / 자식 추가 |
| `F2` 또는 더블클릭 | 노드 편집 |
| `Ctrl/Cmd+Enter` | 편집을 마치고 기록 |
| `Delete` | 노드와 자손 삭제 |
| `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` | 실행 취소, 다시 실행 |
| 드래그 중 `Esc` | 드래그 취소 |
| `Ctrl/Cmd+F` | 검색 열기 |

### 설정

- 어떤 단락 유형을 노드로 표시할지, 어떤 내용을 기본으로 보일지. 두 묶음에 각각 모두 켜기 스위치가 있음
- 데스크톱과 모바일의 기본 레이아웃, 노드 최대 너비, 노드 내용 최대 높이, 파일을 열 때 특정 단계까지만 펼칠지 여부
- 노드의 테두리와 배경에 가지 색을 적용할지, 그리고 노드 안 편집기의 너비와 최대 높이
- 파일별로 보기 상태 기억: 다음에 같은 파일을 열면 접기, 루트, 펼침 단계, 표시 내용을 복원합니다(기본 켜짐, 최대 200개 파일). 기억한 상태를 모두 지우는 버튼도 있습니다

> [!note]
> 모바일에서는 기본 레이아웃이 개요입니다. 드래그 앤 드롭에는 마우스나 펜이 필요하며, 한 손가락으로 끌면 화면이 이동합니다.

> [!note]
> 노드를 편집하는 도중에 파일이 다른 곳에서 바뀌면 그 편집은 기록되지 않습니다.
> 알림이 뜨고 입력한 글이 클립보드에 복사되므로 잃어버리지는 않습니다.

## 명령

보기를 열지 않고 편집기 안에서 제목을 바로 다루는 명령 묶음입니다. 모든 명령은 먼저 현재 노트의 제목을 나열해 고르게 하는 것으로 시작합니다.

### 제목으로 이동
현재 노트의 모든 제목을 찾아 선택한 제목으로 커서를 이동합니다.

### 제목 복사
현재 노트의 제목을 선택하여 복사하거나, 현재 커서 위치에 제목 표식을 삽입합니다.

### 제목 수준 정렬
제목과 모든 내용을 선택한 제목 뒤, 다음 상위 수준 제목 앞에 이동합니다. 이동한 제목은 선택한 제목과 같은 수준으로 조정되며, 하위 제목도 같은 차이만큼 조정됩니다.

> [!important]
> 이 작업은 제목 수준을 변경하여 정렬합니다.

예: H5를 H3에 맞춰 정렬합니다. 플러그인은 H3보다 상위인 다음 제목(H2)을 찾고, H5와 내용을 해당 H2 앞에 이동한 뒤 H5를 H3과 같은 수준으로 변경합니다.

변경 전:
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

변경 후:
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> [!caution]
> Obsidian은 제목 수준 1부터 6까지만 지원합니다. 조정 결과가 6을 초과하면 제목은 수준 6으로 표시됩니다.

예: H3 ✌️를 H4에 맞춰 정렬합니다.
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

변경 후:
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 다른 제목 아래에 제목 삽입
제목과 모든 내용을 선택한 제목 아래, 다음 상위 수준 제목 앞에 이동합니다. 올바른 부모-자식 관계를 유지하도록 제목 수준을 조정합니다.

> [!important]
> 자신의 하위 제목 아래나 현재 부모 제목 아래에는 삽입할 수 없습니다. 해당 제목은 이미 그 부모에 속해 있기 때문입니다.

> [!important]
> 이동할 제목과 대상 제목 사이에 수준 차이가 있으면, 유효한 계층을 유지하도록 수준을 조정합니다.

예: H4를 H2 ☝️ 아래에 삽입합니다.

삽입 전:
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

수준을 바꾸지 않으면 H4는 H2 ☝️의 직접 자식이 아닌 H3의 자식이 됩니다.
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

의도한 구조를 유지하기 위해 H4는 수준 3으로 변경됩니다.
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> [!caution]
> Obsidian은 제목 수준 1부터 6까지만 지원합니다. 조정 결과가 6을 초과하면 제목은 수준 6으로 표시됩니다.

예: H3 ✌️를 H4 아래에 삽입합니다.
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

삽입 후:
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 제목 이동
선택한 제목과 모든 내용을 다른 선택한 제목 뒤, 그 제목의 다음 하위 섹션 앞에 이동합니다. 제목 수준은 변경하지 않습니다.

> [!important]
> 이 작업은 위치만 변경하며 기존 제목 계층을 유지합니다.

예: H1을 H2로 이동하면 플러그인은 다음 제목 H3을 찾아 H1과 H2 내용을 H3 앞에 이동합니다.

이동 전:
```markdown
## H2
### H3
# H1
## H2
```

이동 후:
```markdown
## H2
# H1
## H2
### H3
```

같은 수준의 제목을 다시 정렬할 때도 사용할 수 있습니다.
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

H4 ✌️를 H3으로 이동한 후:
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 현재 블록을 제목 아래로 이동
현재 커서가 있는 블록을 선택한 제목 아래로 이동합니다.

### 선택한 텍스트를 제목 아래로 이동
