# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

Obsidian の Markdown ノートにあるアウトラインとセクションをすばやく整理できます。見出しの移動、コピー、選択、挿入、階層の整列に対応しており、長いノートの再構成や章の並べ替え、見出し階層の維持に役立ちます。

## コマンド

### 見出しへ移動
現在のノート内の見出しを一覧から選択し、カーソルをその見出しへ移動します。

### 見出しをコピー
現在のノート内の見出しを選択し、見出しをコピーするか、現在のカーソル位置に見出し記号を挿入します。

### 見出しレベルを整列
見出しと配下の内容を、選択した見出しの直後かつ次の上位見出しの直前へ移動します。移動する見出しは選択した見出しと同じレベルになり、子見出しも同じ差分だけ調整されます。

> [!important]
> この操作は見出しレベルを変更します。

例：H5 を H3 に整列します。プラグインは H3 より上位の次の見出し（H2）を見つけ、H5 とその内容をその H2 の前へ移動して、H5 を H3 と同じレベルに変更します。

変更前：
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

変更後：
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> [!caution]
> Obsidian はレベル 1 から 6 までの見出しのみをサポートします。調整結果がレベル 6 を超える場合は、レベル 6 として表示されます。

例：H3 ✌️ を H4 に整列します。
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

変更後：
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 別の見出しの下に見出しを挿入
見出しと配下の内容を、選択した見出しの下かつ次の上位見出しの直前へ移動します。正しい親子関係を保つため、見出しレベルも調整されます。

> [!important]
> 自身の子見出しの下、または現在の親見出しの下には挿入できません。すでにその親見出しに属しているためです。

> [!important]
> 移動する見出しと対象の見出しにレベル差がある場合は、有効な階層を維持するようレベルを調整します。

例：H4 を H2 ☝️ の下に挿入します。

変更前：
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

レベルを変更しない場合、H4 は H2 ☝️ の直接の子ではなく H3 の子になります。
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

意図した構造を保つため、H4 はレベル 3 に変更されます。
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> [!caution]
> Obsidian はレベル 1 から 6 までの見出しのみをサポートします。調整結果がレベル 6 を超える場合は、レベル 6 として表示されます。

例：H3 ✌️ を H4 の下に挿入します。
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

変更後：
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 見出しを移動
選択した見出しと配下の内容を、別の選択した見出しの直後かつその次の子セクションの直前へ移動します。見出しレベルは変更しません。

> [!important]
> この操作は位置だけを変更し、既存の見出し階層を保持します。

例：H1 を H2 へ移動すると、次の見出し H3 の前に H1 とその H2 の内容が移動します。

変更前：
```markdown
## H2
### H3
# H1
## H2
```

変更後：
```markdown
## H2
# H1
## H2
### H3
```

同じレベルの見出しの並べ替えにも使えます。
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

H4 ✌️ を H3 へ移動した後：
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 現在のブロックを見出しの下へ移動
カーソル位置を含むブロックを、選択した見出しの下に移動します。

### 選択テキストを見出しの下へ移動
選択中のテキストを、選択した見出しの下に移動します。

### 見出しの内容を選択
選択した見出しの下にあるすべての内容を選択します。
