# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

Markdown 文書をいろいろな角度から眺めるためのプラグインです。
ノート 1 つがマインドマップ 1 枚。見出しやリストなど、もともとある段落をそのまま全体構造の図に描き直し、ノートの要点と構造をすばやく掴めるようにします。

気になるところが見えたら、図の上でそのまま手を入れられます。関係ない枝を折りたたむ、ノードをダブルクリックして中身を書き換える、セクションごと別の章の下へドラッグする。変更はすべてノートに書き戻されるので、エディターを上下にスクロールして切り貼りする必要はありません。
ほかに、ビューを開かずにエディター内で見出しへ移動・コピー・移動したり、ずれた見出しレベルを揃えたりするコマンドも一式あります。

いま開いているノートを 1 枚の図に描きます。図の上で折りたたみ・編集・ドラッグをすると、変更はファイルに書き戻されます。

リボンアイコンをクリックするか、コマンド **Headings ビューを開く** を実行すると開きます。
ビューに表示されるのはいま開いているノートで、ノートを切り替えたりファイルの内容が変わったりすると追従して更新されます。

### レイアウト

レイアウトは 3 種類あり、ビューのヘッダーから切り替えます。

- マインドマップ：ノート名を中央に置き、見出しが左右へ伸びていきます。ホイールでパン、ピンチまたは Ctrl+ホイールでズーム。
- ツリーテーブル：見出しを入れ子のセルとして並べ、右に 1 列進むごとに 1 階層深くなります。
- アウトライン：枝線付きのインデントリスト。

デスクトップとモバイルそれぞれの既定レイアウトは設定で変えられます。
特定のノートだけレイアウトを固定したい場合は、プロパティに `headings-layout` を追加し、値を `mindmap`、`tree-table`、`outline` のいずれかにします。マインドマップは右側だけに伸ばすこともできます。レイアウトメニューの **マインドマップ：右側のみ** にチェックを入れるか、設定で既定にするか、ノートのプロパティに `headings-mindmap-direction: right` を追加します。

### ノード

見出し 1 つがノード 1 つになり、見出しの下にある段落（本文、リスト、引用、Callout、コード、表、数式、HTML、プロパティ、脚注）はノードの中に入ります。
ノード上のアイコンの列で、種類ごとに段落の表示・非表示を切り替えられます。既定でどの種類を表示するかは設定で選びます。

ある種類の段落を独立したノードにしたい場合（たとえばリストの各項目をそれぞれ子ノードにする）、設定でその種類にチェックを入れるか、ノートのプロパティに `headings-nodes` を追加して指定します。ヘッダーのメニューから一時的に切り替えることもできます。

ノートのプロパティ（フロントマター）はルートノードにプロパティパネルとして表示されます。
ノード内のチェックボックスはそのままオンオフでき、ファイルに書き戻されます。

### 移動

ビューの上部にパンくずがあり、選択中ノードまでのパスを示します。項目をクリックすると同じ階層の兄弟ノードが一覧され、選ぶとそこへジャンプします。

折りたたみと展開にはいくつか方法があります。枝の分岐点にあるハンドルをクリックする、ノードを選択して `Space` で子ノードを折りたたみ・展開（`Shift+Space` ならサブツリー全体）、またはヘッダーのメニューで何階層目まで展開するかを指定する。**1 レベル展開** と **1 レベル折りたたむ** はコマンドにもなっているので、ホットキーを割り当てられます。

ノードを右クリックするか `…` をクリックするとノードメニューが開きます。

- 他のノードを折りたたむ
- このノードをルートにする：そのサブツリーだけを表示。戻るにはパンくずをクリック
- このサブツリーを展開 / 折りたたむ
- Markdown ファイル内で位置を表示：エディターのカーソルをこのノードに対応する行へ移す

矢印キーで、表示中のノード間を選択移動できます。

ヘッダーの検索ボタン、コマンド **ノードを検索**、またはビューにフォーカスがあるときの `Ctrl/Cmd+F` で、パンくずの上に検索バーが開きます。見出しとノード内容の原文を比較します。複数の語は空白で区切るとすべて一致したものだけ、大文字小文字は区別せず、引用符でフレーズをまとめられます。範囲はいま描かれているツリーで、**このノードをルートにする** のあとはそのサブツリーだけを検索します。そのとき検索バーに「『…』内」のラベルが出て、クリックするとファイル全体に戻ります。

検索バーのじょうごボタンで 2 つのモードを切り替えます。前回の選択を覚えています。

- 検索（既定）：ツリー全体をそのまま描き、一致したノードを検索ハイライト色（エディターの Ctrl+F と同じ）で示し、現在の一致はより濃い色になります。`Enter` / `Shift+Enter` で一致の間を移動して中央に表示し、折りたたまれていれば途中で展開します。ほかの操作はすべて通常どおりです。
- フィルター：一致したノードとその祖先だけを残し、通り道になっただけの祖先は薄くなり、折りたたみ状態は一時的に無視されます。これは「見る」ためのレンズで、編集の作業面ではありません。追加、削除、ドラッグ、`Space`、折りたたみ関連のメニューはフィルター中は無効です。選択、矢印キー、内容の編集、チェックボックス、位置表示、このノードをルートにするは使えます。

`Esc` で検索バーを閉じると、ツリーは元の状態に戻ります。

### 編集

ノードをダブルクリック、`F2`、またはノードメニューの **編集** を選ぶと、ノードが Obsidian のエディターに変わり、そのノードの Markdown が入っています。
同じエディターなので、リスト、リンク、タグ、書式の挙動はノート内とまったく同じです。

`Ctrl/Cmd+Enter` を押すか、ノードの外側をクリックするとファイルに書き戻されます。
それ以外のキーは一切横取りしません。`Enter` はこれまでどおりリストを続け、`Esc` は選択を解除します。

ノードを選択中（編集中でないとき）：

- `Enter` で後ろに兄弟ノードを追加
- `Tab` で子ノードを追加
- `Delete` でノードとその下にあるものをすべて削除（先に確認が出ます）
- `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` で元に戻す・やり直し

追加や削除のあと、見出しレベルとリストのインデントは自動で調整されるので、自分で直す必要はありません。

### ドラッグ＆ドロップ

ノードのタイトル行を長押しするとドラッグできます。
ドラッグ中はプレースホルダーがドロップ先を示し、他のノードが場所を空けます。

- ノードの中央にドロップすると、そのノードの最後の子になる
- ノードの上端または下端にドロップすると、そのノードの前または後に挿入される
- `Esc` でキャンセル

表示されるのは許可されたドロップ先だけです。見出しは見出しの隣に、リスト項目はリスト項目の隣にしか置けません。
ドロップ後、見出しレベルとリストのインデントは新しい親に合わせて調整されます。

### キーボード

| キー | 動作 |
|---|---|
| `↑` `↓` `←` `→` | 選択を移動 |
| `Space` / `Shift+Space` | 子ノード / サブツリー全体を折りたたむ・展開 |
| `Enter` / `Tab` | 兄弟 / 子を追加 |
| `F2` またはダブルクリック | ノードを編集 |
| `Ctrl/Cmd+Enter` | 編集を終えて書き戻す |
| `Delete` | ノードと子孫を削除 |
| `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` | 元に戻す、やり直し |
| ドラッグ中の `Esc` | ドラッグをキャンセル |
| `Ctrl/Cmd+F` | 検索を開く |

### 設定

- どの種類の段落をノードとして表示するか、どの内容を既定で表示するか。それぞれに一括切り替えのスイッチあり
- デスクトップとモバイルの既定レイアウト、ノードの最大幅、ノード内容の最大高さ、ファイルを開いたときに特定の階層までしか展開しないかどうか
- ノードの枠線と背景にブランチの色を使うかどうか、ノード内エディターの幅と最大高さ
- ファイルごとにビューの状態を記憶：次に同じファイルを開いたとき、折りたたみ、ルート、展開レベル、表示内容を復元します（既定でオン、最大 200 ファイル）。記憶した状態をすべて消去するボタンもあります

> [!note]
> モバイルでは既定でアウトラインになります。ドラッグ＆ドロップにはマウスまたはペンが必要で、1 本指のドラッグは画面のパンになります。

> [!note]
> ノードの編集中に別の場所でファイルが変更された場合、その編集は書き戻されません。
> 通知が表示され、入力したテキストはクリップボードにコピーされるので失われません。

## コマンド

ビューを開かずにエディター内で見出しを直接操作するためのコマンド群です。どのコマンドも、まず現在のノートの見出しを一覧して選ぶところから始まります。

### 見出しへ移動
現在のノート内の見出しを一覧から選択し、カーソルをその見出しへ移動します。

### 見出しをコピー
現在のノート内の見出しを選択し、見出しをコピーするか、現在のカーソル位置に見出し記号を挿入します。

### 見出しレベルを整列
見出しと配下の内容を、選択した見出しの直後かつ次の上位見出しの直前へ移動します。移動する見出しは選択した見出しと同じレベルになり、子見出しも同じ差分だけ調整されます。

> [!important]
> この操作は見出しレベルを変更します。

例：H5 を H3 に整列します。プラグインは H3 より上位の次の見出し（H2）を見つけ、H5 とその内容をその H2 の前へ移動して、H5 を H3 と同じレベルに変更します。

変更前：
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

変更後：
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> [!caution]
> Obsidian はレベル 1 から 6 までの見出しのみをサポートします。調整結果がレベル 6 を超える場合は、レベル 6 として表示されます。

例：H3 ✌️ を H4 に整列します。
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

変更後：
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 別の見出しの下に見出しを挿入
見出しと配下の内容を、選択した見出しの下かつ次の上位見出しの直前へ移動します。正しい親子関係を保つため、見出しレベルも調整されます。

> [!important]
> 自身の子見出しの下、または現在の親見出しの下には挿入できません。すでにその親見出しに属しているためです。

> [!important]
> 移動する見出しと対象の見出しにレベル差がある場合は、有効な階層を維持するようレベルを調整します。

例：H4 を H2 ☝️ の下に挿入します。

変更前：
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

レベルを変更しない場合、H4 は H2 ☝️ の直接の子ではなく H3 の子になります。
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

意図した構造を保つため、H4 はレベル 3 に変更されます。
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> [!caution]
> Obsidian はレベル 1 から 6 までの見出しのみをサポートします。調整結果がレベル 6 を超える場合は、レベル 6 として表示されます。

例：H3 ✌️ を H4 の下に挿入します。
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

変更後：
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 見出しを移動
選択した見出しと配下の内容を、別の選択した見出しの直後かつその次の子セクションの直前へ移動します。見出しレベルは変更しません。

> [!important]
> この操作は位置だけを変更し、既存の見出し階層を保持します。

例：H1 を H2 へ移動すると、次の見出し H3 の前に H1 とその H2 の内容が移動します。

変更前：
```markdown
## H2
### H3
# H1
## H2
```

変更後：
```markdown
## H2
# H1
## H2
### H3
```

同じレベルの見出しの並べ替えにも使えます。
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

H4 ✌️ を H3 へ移動した後：
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 現在のブロックを見出しの下へ移動
カーソル位置を含むブロックを、選択した見出しの下に移動します。

### 選択テキストを見出しの下へ移動
選択中のテキストを、選択した見出しの下に移動します。

### 見出しの内容を選択
選択した見出しの下にあるすべての内容を選択します。
