# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

快速整理 Obsidian Markdown 笔记的大纲与段落。本插件提供标题导航、复制、选择、移动、插入和层级对齐，适合重组长笔记、调整章节顺序或维护标题层级。

## 命令

### 前往标题
浏览当前笔记中的所有标题，并将光标移动到所选标题。

### 复制标题
浏览当前笔记中的所有标题。选择后可复制标题，或在当前光标位置插入标题标记。

### 对齐标题层级
将标题及其全部内容移动到所选标题之后、下一个更高层级标题之前。移动的标题会调整为与所选标题相同的层级，子标题也会相应调整。

> 此操作会修改标题层级以进行对齐。

示例：将 H5 对齐到 H3。插件会找到 H3 后第一个更高层级的标题（H2），将 H5 及其内容移动到该 H2 之前，并将 H5 调整为 H3 的层级。

调整前：
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

调整后：
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> Obsidian 仅支持 1 至 6 级标题。调整后超过 6 级的标题会显示为 6 级。

示例：将 H3 ✌️ 对齐到 H4。

调整前：
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

调整后：
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 将标题插入到另一标题下
将标题及其全部内容移动到所选标题下、其下一个更高层级标题之前。插入的标题会调整层级，以保持正确的父子关系。

> 不能插入到自身的子标题下，也不能插入到当前父标题下，因为该标题本来就属于当前父标题。

> 只要移动标题与目标标题存在层级差，插件就会调整移动标题的层级以保持有效的结构。

示例：将 H4 插入到 H2 ☝️ 下。

插入前：
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

不调整层级时，H4 会成为 H3 的子内容，而不是 H2 ☝️ 的直接子内容：
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

为保持预期结构，H4 会调整为第 3 级：
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> Obsidian 仅支持 1 至 6 级标题。调整后超过 6 级的标题会显示为 6 级。

示例：将 H3 ✌️ 插入到 H4 下。

插入前：
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

插入后：
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 移动标题
将所选标题及其全部内容移动到另一所选标题之后、该标题下一个子章节之前。此命令不会改变标题层级。

> 此操作只改变标题及其内容的位置，保留原有标题层级。

示例：将 H1 移至 H2 时，插件会找到下一个标题 H3，并将 H1 及其 H2 内容移动到 H3 前，不改变层级。

移动前：
```markdown
## H2
### H3
# H1
## H2
```

移动后：
```markdown
## H2
# H1
## H2
### H3
```

也可用于重新排列同级标题。

移动前：
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

将 H4 ✌️ 移至 H3 后：
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 将当前区块移至标题下
将当前光标所在的区块移至所选标题下。

### 将选中文本移至标题下
将当前选中的文本移至所选标题下。

### 选择标题内容
选择所选标题下的全部内容。
