# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

一个从不同角度浏览 Markdown 文档的插件。
一则笔记就是一张思维导图：标题、列表等原本的段落，重新画成一张整体结构的图，让你快速掌握笔记的重点与结构。

看出问题就直接在图上动手：折叠不相干的分支、双击节点修改内容、把整段拖到别的章节下面，改动都会写回笔记，不用回编辑器上下滚动剪贴。
另外有一组编辑器内的命令，不开视图也能前往、复制、移动标题，或把跑偏的标题层级对齐。


## Headings view

<!-- 待补图：doc/img/headings_view_mindmap.png（思维导图全貌）、doc/img/headings_view_drag.gif（拖拽与落点预览）、doc/img/headings_view_edit.gif（节点内编辑）。脚本见 doc/demo/recording-script.md。 -->

把当前打开的笔记画成一张图，在图上折叠、编辑、拖拽，改动会写回文件。

点击侧栏图标，或执行命令 **打开 Headings 视图** 就会打开。
视图显示的是当前打开的笔记，切换笔记或文件内容改变时会跟着更新。

### 布局

有三种布局，从视图的标题栏切换：

- 思维导图：文件名在中间，标题向左右两侧长出去。滚轮可以平移，双指或 Ctrl+滚轮缩放。
- 树状表格：标题排成嵌套的格子，每向右一列就深一层。
- 大纲：有分支线的缩进列表。

桌面与手机各自的默认布局在设置里调。
如果某篇笔记想固定用某种布局，在属性里加 `headings-layout`，值可以是 `mindmap`、`tree-table` 或 `outline`。思维导图可以只向右生长：在布局菜单勾选 **思维导图只向右**，或在设置里设为默认，或在笔记属性里加 `headings-mindmap-direction: right`。

### 节点

每个标题就是一个节点，标题下的段落（文字、列表、引用、callout、代码、表格、数学、HTML、属性、脚注）会放在节点里面。
节点上有一排图标，可以按类型把段落显示或隐藏；默认显示哪些类型在设置里选。

如果希望某种段落也变成独立的节点（例如列表的每一项都变成一个子节点），可以在设置里勾选类型，或者在笔记属性里加 `headings-nodes` 指定；标题栏的菜单也可以临时切换。

笔记的属性（frontmatter）会以属性面板的形式放在根节点。
节点里的复选框可以直接勾选，会写回文件。

### 浏览

视图顶部有面包屑，显示当前选中节点的路径。点击其中一段会列出该层的兄弟节点，选了就跳过去。

折叠与展开有几种方式：点击分支分叉处的把手；选中节点后按 `Space` 折叠或展开子节点，`Shift+Space` 则是整棵子树；或者从标题栏菜单指定要展开到第几层。**展开一层** 和 **折叠一层** 也有对应的命令可以绑快捷键。

在节点上右键或点击 `…` 会出现节点菜单：

- 折叠其他节点
- 以此为根：只显示这个子树，要返回的话点击面包屑
- 展开 / 折叠此子树
- 在 Markdown 文件中定位：把编辑器的光标移到这个节点对应的那一行

方向键可以在可见的节点之间移动选择。

标题栏的搜索按钮、命令 **搜索节点**，或视图有焦点时按 `Ctrl/Cmd+F`，会在面包屑上方打开搜索栏。匹配的是标题与节点内容的原文：多个词用空格分开需全部命中，不分大小写，引号可以包住短语。范围是当前画出的树，用了**以此为根**就只搜那个子树，搜索栏会多一个「在『…』内」的标签，点它回到整个文件。

搜索栏上的漏斗按钮切换两种模式，会记住上次的选择：

- 搜索（默认）：整棵树照画，命中的节点用搜索高亮色（与编辑器 Ctrl+F 相同）标出，当前跳到的那个颜色更深。`Enter` / `Shift+Enter` 在命中之间跳转并居中，折叠着的会顺路展开。其他操作全部照常。
- 过滤：只留下命中的节点和它们的祖先，路过的祖先变淡，折叠状态暂时忽略。这是用来「看」的镜片，不是改的工作面：新增、删除、拖拽、`Space` 与折叠相关的菜单在过滤中停用；选择、方向键、编辑内容、勾选复选框、定位、以此为根照常。

`Esc` 关闭搜索栏，树回到原本的样子。

### 编辑

双击节点、按 `F2`，或从节点菜单选 **编辑**，节点就会变成 Obsidian 的编辑器，里面是这个节点的 Markdown。
列表、链接、标签、格式等的行为都和在笔记里一样，因为就是同一个编辑器。

按 `Ctrl/Cmd+Enter` 或点击节点外面就会写回文件。
除此之外不会拦截任何按键，`Enter` 还是延续列表、`Esc` 还是取消选择。

选中节点（不在编辑状态）时：

- `Enter` 在后面新增一个兄弟节点
- `Tab` 新增一个子节点
- `Delete` 删除节点和它下面的所有内容，会先弹出确认
- `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 撤销、重做

新增或删除之后，标题层级和列表缩进会自动调整，不用自己改。

### 拖拽

按住节点的标题栏就能拖。
拖的时候会有一个占位框显示放下去会落在哪里，其他节点会让出空间。

- 放在节点中间，会变成它的最后一个子节点
- 放在节点上缘或下缘，会插在它前面或后面
- 按 `Esc` 取消

只会出现合法的落点：标题只能放在标题旁边，列表项只能放在列表项旁边。
放下之后，标题层级和列表缩进会跟着新的父节点调整。

### 键盘

| 按键 | 动作 |
|---|---|
| `↑` `↓` `←` `→` | 移动选择 |
| `Space` / `Shift+Space` | 折叠或展开子节点 / 整棵子树 |
| `Enter` / `Tab` | 新增兄弟 / 子节点 |
| `F2` 或双击 | 编辑节点 |
| `Ctrl/Cmd+Enter` | 完成编辑并写回 |
| `Delete` | 删除节点及其后代 |
| `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` | 撤销、重做 |
| 拖动中按 `Esc` | 取消拖动 |
| `Ctrl/Cmd+F` | 打开搜索 |

### 设置

- 哪些段落类型要显示为节点、哪些内容默认显示，两组各有一个全选开关
- 桌面与手机的默认布局、节点最大宽度、节点内容最大高度、打开文件时是否只展开到某一层
- 节点的边框和背景是否应用分支颜色，以及节点内编辑器的宽度和最大高度
- 记住每个文件的视图状态：下次打开同一文件时恢复折叠、聚焦、展开层级与显示的内容（默认开启，最多记 200 个文件），旁边有清除所有记录的按钮

> [!note]
> 手机默认是大纲布局。拖拽需要鼠标或手写笔，单指拖动是平移画面。

> [!note]
> 编辑节点的过程中，如果文件在别处被修改过，这次的编辑不会写回，
> 会弹出通知，并把你输入的内容复制到剪贴板，避免丢失。

## 命令

在编辑器里直接操作标题的一组命令，不需要打开视图。每个命令都会先列出当前笔记的标题让你挑。

### 前往标题
浏览当前笔记中的所有标题，并将光标移动到所选标题。

### 复制标题
浏览当前笔记中的所有标题。选择后可复制标题，或在当前光标位置插入标题标记。

### 对齐标题层级
将标题及其全部内容移动到所选标题之后、下一个更高层级标题之前。移动的标题会调整为与所选标题相同的层级，子标题也会相应调整。

> [!important]
> 此操作会修改标题层级以进行对齐。

示例：将 H5 对齐到 H3。插件会找到 H3 后第一个更高层级的标题（H2），将 H5 及其内容移动到该 H2 之前，并将 H5 调整为 H3 的层级。

调整前：
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```

调整后：
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

> [!caution]
> Obsidian 仅支持 1 至 6 级标题。调整后超过 6 级的标题会显示为 6 级。

示例：将 H3 ✌️ 对齐到 H4。

调整前：
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

调整后：
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 将标题插入到另一标题下
将标题及其全部内容移动到所选标题下、其下一个更高层级标题之前。插入的标题会调整层级，以保持正确的父子关系。

> [!important]
> 不能插入到自身的子标题下，也不能插入到当前父标题下，因为该标题本来就属于当前父标题。

> [!important]
> 只要移动标题与目标标题存在层级差，插件就会调整移动标题的层级以保持有效的结构。

示例：将 H4 插入到 H2 ☝️ 下。

插入前：
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

不调整层级时，H4 会成为 H3 的子内容，而不是 H2 ☝️ 的直接子内容：
```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```

为保持预期结构，H4 会调整为第 3 级：
```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

> [!caution]
> Obsidian 仅支持 1 至 6 级标题。调整后超过 6 级的标题会显示为 6 级。

示例：将 H3 ✌️ 插入到 H4 下。

插入前：
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

插入后：
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```

### 移动标题
将所选标题及其全部内容移动到另一所选标题之后、该标题下一个子章节之前。此命令不会改变标题层级。

> [!important]
> 此操作只改变标题及其内容的位置，保留原有标题层级。

示例：将 H1 移至 H2 时，插件会找到下一个标题 H3，并将 H1 及其 H2 内容移动到 H3 前，不改变层级。

移动前：
```markdown
## H2
### H3
# H1
## H2
```

移动后：
```markdown
## H2
# H1
## H2
### H3
```

也可用于重新排列同级标题。

移动前：
```markdown
## H2
### H3
#### H4 ☝️
#### H4 ✌️
```

将 H4 ✌️ 移至 H3 后：
```markdown
## H2
### H3
#### H4 ✌️
#### H4 ☝️
```

### 将当前区块移至标题下
将当前光标所在的区块移至所选标题下。

### 将选中文本移至标题下
将当前选中的文本移至所选标题下。

### 选择标题内容
选择所选标题下的全部内容。
