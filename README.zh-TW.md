# Headings

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md)

一個從不同角度瀏覽 Markdown 文件的插件。
一則筆記就是一張心智圖：標題、清單等原本的段落，重新畫成一張整體結構的圖，讓你快速掌握筆記的重點與結構。

看出問題就直接在圖上動手：收合不相干的分支、雙擊節點修改內容、把整段拖到別的章節底下，改動都會寫回筆記，不用回編輯器上下捲動剪貼。
另外有一組編輯器內的指令，不開視圖也能前往、複製、移動標題，或把跑掉的標題階層對齊。


## Headings view

<!-- 待補圖：doc/img/headings_view_mindmap.png（心智圖全貌）、doc/img/headings_view_drag.gif（拖曳與落點預覽）、doc/img/headings_view_edit.gif（節點內編輯）。腳本見 doc/demo/recording-script.md。 -->

把目前開著的筆記畫成一張圖，在圖上收合、編輯、拖曳，改動會寫回檔案。

點側欄圖示，或執行指令 **開啟 Headings 視圖** 就會打開。
視圖顯示的是目前開著的筆記，切換筆記或檔案內容改變時會跟著更新。

### 佈局

有三種佈局，從視圖的標題列切換：

- 心智圖：檔名在中間，標題往左右兩側長出去。滾輪可以平移，雙指或 Ctrl+滾輪縮放。
- 樹狀表格：標題排成巢狀的格子，每往右一欄就深一層。
- 大綱：有分支線的縮排清單。

桌面與手機各自的預設佈局在設定裡調。
如果某篇筆記想固定用某種佈局，在屬性加 `headings-layout`，值可以是 `mindmap`、`tree-table` 或 `outline`。心智圖可以只往右長：在佈局選單勾選 **心智圖只往右**，或在設定裡設為預設，或在筆記屬性加 `headings-mindmap-direction: right`。

### 節點

每個標題就是一個節點，標題底下的段落（文字、清單、引用、callout、程式碼、表格、數學、HTML、屬性、腳註）會放在節點裡面。
節點上有一排圖示，可以依型別把段落顯示或隱藏；預設要顯示哪些型別在設定裡選。

如果希望某種段落也變成獨立的節點（例如清單的每一項都變成一個子節點），可以在設定裡勾選型別，或是在筆記屬性加 `headings-nodes` 指定；標題列的選單也可以臨時切換。

筆記的屬性（frontmatter）會以屬性面板的形式放在根節點。
節點裡的核取方塊可以直接勾，會寫回檔案。

### 瀏覽

視圖上方有麵包屑，顯示目前選取節點的路徑。點其中一段會列出該層的兄弟節點，選了就跳過去。

收合與展開有幾種方式：點分支分叉處的把手；選取節點後按 `Space` 收合或展開子節點，`Shift+Space` 則是整棵子樹；或是從標題列選單指定要展開到第幾層。**展開一層** 和 **收合一層** 也有對應的指令可以綁快捷鍵。

在節點上按右鍵或點 `…` 會有節點選單：

- 收合其他節點
- 以此為根：只顯示這個子樹，要回去的話點麵包屑
- 展開 / 收合此子樹
- 在 Markdown 文件定位：把編輯器的游標移到這個節點對應的那一行

方向鍵可以在看得到的節點之間移動選取。

標題列的搜尋按鈕、指令 **搜尋節點**，或視圖有焦點時按 `Ctrl/Cmd+F`，會在麵包屑上方打開搜尋列。比對的是標題與節點內容的原文：多個詞用空白分開要全部命中，不分大小寫，引號可以包住片語。範圍是目前畫的樹，用了**以此為根**就只搜那個子樹，搜尋列會多一個「在『…』內」的標籤，點它回到整份檔案。

搜尋列上的漏斗鈕切換兩種模式，會記住上次的選擇：

- 搜尋（預設）：整棵樹照畫，命中的節點用搜尋高亮色（跟編輯器 Ctrl+F 一樣）標出，目前跳到的那個顏色更深。`Enter` / `Shift+Enter` 在命中之間跳並置中，收合著的會順路展開。其他操作全部照常。
- 過濾：只留下命中的節點和它們的祖先，路過的祖先變淡，收合狀態暫時忽略。這是用來「看」的鏡片，不是改的工作面：新增、刪除、拖曳、`Space` 與收合相關的選單在過濾中停用；選取、方向鍵、編輯內容、勾核取方塊、定位、以此為根照常。

`Esc` 關閉搜尋列，樹回到原本的樣子。

### 編輯

雙擊節點、按 `F2`，或從節點選單選 **編輯**，節點就會變成 Obsidian 的編輯器，裡面是這個節點的 Markdown。
清單、連結、標籤、格式等等的行為都跟在筆記裡一樣，因為就是同一個編輯器。

按 `Ctrl/Cmd+Enter` 或點節點外面就會寫回檔案。
除此之外不會攔截任何按鍵，`Enter` 還是接續清單、`Esc` 還是取消選取。

選取節點（不在編輯狀態）時：

- `Enter` 在後面新增一個兄弟節點
- `Tab` 新增一個子節點
- `Delete` 刪除節點和它底下的所有東西，會先跳確認
- `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 復原、重做

新增或刪除之後，標題階層和清單縮排會自動調整，不用自己改。

### 拖曳

在節點的標題列按住就能拖。
拖的時候會有一個佔位框顯示放下去會落在哪裡，其他節點會讓出空間。

- 放在節點中間，會變成它的最後一個子節點
- 放在節點上緣或下緣，會插在它前面或後面
- 按 `Esc` 取消

只會出現合法的落點：標題只能放在標題旁邊，清單項只能放在清單項旁邊。
放下去之後，標題階層和清單縮排會跟著新的父節點調整。

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| `↑` `↓` `←` `→` | 移動選取 |
| `Space` / `Shift+Space` | 收合或展開子節點 / 整棵子樹 |
| `Enter` / `Tab` | 新增兄弟 / 子節點 |
| `F2` 或雙擊 | 編輯節點 |
| `Ctrl/Cmd+Enter` | 完成編輯並寫回 |
| `Delete` | 刪除節點與其後代 |
| `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` | 復原、重做 |
| 拖曳中按 `Esc` | 取消拖曳 |
| `Ctrl/Cmd+F` | 開啟搜尋 |

### 設定

- 哪些段落類型要顯示成節點、哪些內容預設要顯示，兩組各有一個全選開關
- 桌面與手機的預設佈局、節點最大寬度、節點內容最大高度、開檔時是否只展開到某一層
- 節點的邊框和背景要不要套用分支顏色，以及節點內編輯器的寬度和最大高度
- 記住每個檔案的視圖狀態：下次開同一個檔案時恢復收合、聚焦、展開層數與顯示的內容（預設開啟，最多記 200 個檔案），旁邊有清除所有記錄的按鈕

> [!note]
> 手機預設是大綱佈局。拖曳需要滑鼠或手寫筆，單指拖動是平移畫面。

> [!note]
> 編輯節點的途中，如果檔案在別的地方被改過，這次的編輯不會寫回，
> 會跳通知，並把你打的內容複製到剪貼簿，避免弄丟。

## Commands

在編輯器裡直接操作標題的一組指令，不需要開視圖。每個指令都會先列出目前筆記的標題讓你挑。

### 前往標題
瀏覽目前筆記的所有標題，並將游標跳至所選標題的位置。

### 複製標題
瀏覽目前筆記的所有標題，選擇後可複製標題，或插入標題符號至目前游標位置。


### 對齊標題階層
移動標題整體至所選擇的標題至下一個大標題之間，
並修改移動的標題階層與選擇的標題的階層一致。

> [!important]
> 會修改標題階層，以對齊標題階層

範例：
對齊 H5 至 H3，
則會找到下一個比 H3 大的標題(H2)，
將 H5 底下的內容移至 H2 之前，
並且更改 H5 的階層以對齊 H3。

對齊前
```markdown
## H2
### H3
#### H4
## H2
##### H5
###### H6
```
對齊後
```markdown
## H2
### H3
#### H4
### H5
#### H6
## H2
```

>[!caution]
> obsidian 支援的階層只到 Level 6(######)，
> 如果判斷需要更改階層但超過 Level 6 的標題，皆會以 Level 6 顯示 

範例：

對齊 H3 ✌️ 至 H4。

對齊前
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

對齊後
```markdown
## H2
### H3
#### H4
##### H5
#### H3 ✌️
##### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2
```
### 將標題插入另一標題下
移動標題整體至所選擇的標題至下一個大標題之間，
會修改選擇的標題階層以符合整體階層，
保持插入的標題正確的歸屬於所選擇的標題之下。

> [!Important]
> 不能插入到自己的子標題底下，也不能插入到當前標題底下，因為自己本身就屬於當前標題了。

> [!Important]
> 無論原標題是否需要更改階層才能符合整體階層，
> 只要插入的標題與被插入的標題之間有階層差距，
> 都會修改原標題的階層，用以保持標準的階層結構設計。

範例：

想將 H4 插入至 H2 ☝️ 底下，

插入前
```markdown
## H2 ☝️
### H3
## H2
#### H4
```

如果標題級距不跟著改，
H4 會變成屬於 H3 的子內容，而不是 H2 的子內容，

```markdown
## H2 ☝️
### H3
#### H4 ❌
## H2
```
這並不符合操作意圖，所以會修改 H4 的階層至 level 3，
以符合操作意圖，

```markdown
## H2 ☝️
### H3
### H4 ⭕
## H2
```

>[!caution]
> obsidian 支援的階層只到 Level 6(######)，
> 如果判斷需要更改階層但超過 Level 6 的標題，皆會以 Level 6 顯示 

範例：

插入 H3 ✌️ 至 H4 底下，

插入前
```markdown
## H2
### H3
#### H4
##### H5
## H2
### H3 ✌️
#### H4 ✌️
##### H5 ✌️
###### H6 ✌️
```

插入後
```markdown
## H2
### H3
#### H4
##### H5
##### H3 ✌️
###### H4 ✌️
###### H5 ✌️
###### H6 ✌️
## H2

```

### 移動標題
移動選擇的標題及其所涵蓋的內容至另一個標題到下一個標題的段落之間。

> [!Important]
> 此指令只是單純的移動標題內容位置，
> 不會更改原有的標題階層。

範例:

如果移動 H1 至 H2 ，那麼會從 H2 找到下一個標題 H3，
將 H1 及底下的 H2 內容，移動至 H3 之前，
並不會改變 H1 底下內容的階層

移動前
```markdown
## H2
### H3
# H1
## H2
```

移動後
```markdown
## H2
# H1
## H2
### H3
```


### 將目前區塊移至標題下
將目前游標所在的區塊移至所選標題底下。

### 將選取文字移至標題下
將目前選取的文字範圍移至所選標題底下。

### 選取標題內容
選取所選標題底下的所有內容。
